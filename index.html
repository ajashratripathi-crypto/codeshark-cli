Do I need an API key?+

You can start with the shared community gateway without a key. For your own provider access, run codeshark setup and add your key. Shared lanes have rate limits and depend on provider availability.

What can CodeShark do in my project?+

It can read and search files, propose a plan, edit code, and run shell commands. You select the project folder, and every tool action asks for approval before it runs.

Is my code sent to a model provider?+

When you use a hosted model, prompts and the relevant project content are sent through your configured connection. Your provider’s data policies apply. You can also configure local Ollama. See the Privacy Notice for details.

How do I switch models?+

Use /model inside a session to see your choices. Copy a model command from the lineup above to select it directly. Your selection is saved locally.

Is CodeShark actually open source?+

Yes. CodeShark is MIT licensed. You can read the source, build it yourself, and contribute on GitHub. The CLI is free; any costs or limits for your own provider account are set by that provider.
