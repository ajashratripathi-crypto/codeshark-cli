Less context switching.

CodeShark stays close to your code. No dashboards, no copy-pasting back and forth. Just an agent in the folder where the work lives.

Native to Terminal

Keep your editor, shell, and Git workflow in one place. Ask for a change without breaking your rhythm.

Folder Scoped

By passing the `--folder .` flag, the agent is strictly bound to your current workspace, ensuring safe reads and edits.

Built for Changes

It doesn't just chat. It searches references, edits files directly, and can run your test suites to verify its work.

$npm install -g codeshark-cli
2. Run in your project folder
$codeshark
